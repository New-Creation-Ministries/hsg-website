# HSG Website

## About

HSG Website is the planned official digital home for Holy Spirit Generation. It will give members and newcomers a clear, mobile-friendly place to find services, events, announcements, testimonies, prayer and contact options, and online giving. The initial release is focused on India, with a foundation that can support additional regions later.

## Development workflow

This repository uses BMad, an agent-guided product planning and development framework. Its specialized workflows turn an idea into traceable artifacts—from research and product requirements through UX, architecture, epics, stories, implementation, testing, and review.

1. Create or update the relevant planning artifact before implementation.
2. Review and approve decisions before using them as inputs to downstream work.
3. Implement against an approved story or specification, keeping code, tests, and documentation aligned.
4. Run the relevant quality checks and add any new project documents to the index below.

The `_bmad/` directory contains the installed BMad workflows and configuration. Project-specific artifacts created by those workflows live in `_bmad-output/`.
